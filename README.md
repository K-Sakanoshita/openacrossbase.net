# Open Across Base

地図とオープンデータを使って、まちを記録し、見つけ、伝えるための活動・プロジェクトをまとめるポータルサイトです。

OpenStreetMap、Wikimedia、地域活動などを横断しながら制作・運営しているWebサイトやツールを紹介しています。

## Webサイト

- https://www.openacrossbase.net/

## Projects

- [まち歩きマップメーカー](https://armd-02.github.io/mapmaker/)
  - OpenStreetMapを使った、まち歩きや地域活動向けの地図作成ツール
- [OSM What's New Japan](https://armd-01.sakura.ne.jp/whatsnew/)
  - 日本国内でOpenStreetMapに追加・更新された地物を見つけるためのダッシュボード
- [遊具のある公園マップ](https://armd-02.github.io/Playgrounds/)
  - 遊具や公園の情報を地図から探すWebマップ
- [少し昔の地図を見てみよう](https://armd-02.github.io/TimeMapTravel_Japan/)
  - 現在の地図と少し昔の地図を比較しながら見るためのWebマップ
- [大阪思い出のこしマップ](https://armd-02.github.io/OsakaMemories/)
  - 大阪市立図書館の「思い出のこしプロジェクト」で公開されている情報を地図で閲覧するツール
- [日本のPMTiles配布サイト](https://armd-01.sakura.ne.jp/tiles/)
  - Web地図などで利用できる日本のPMTilesデータを公開
- [長浜城下町遺産マップ](https://armd-02.github.io/NagahamaJyoukamachi/)
  - 長浜城下町遺産と周辺の文化・歴史的な地物を閲覧できるWebマップ
- [Easy Changeset Viewer](https://github.com/K-Sakanoshita/Easy_Changeset_Viewer)
  - OpenStreetMapの編集履歴（Changeset）をWeb上で簡単に確認するためのツール
